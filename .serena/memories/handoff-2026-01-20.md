## Completed Work

### 1. Workflow State Caching (Committed: 3cfe3c1)

**Problem:** Workflow state was being lost mid-session because:
- Router spawns `workflow_server.py` as subprocess
- On any communication error, router kills connection and respawns new process
- New process has empty `self._workflows` dict → state lost

**Solution:** Added shadow caching to MCPRouter:
- `_workflow_state_cache` dict in `MCPRouter.__init__`
- `_cache_workflow_state()` - caches state on set/start operations
- `_restore_workflow_state()` - restores state when backend respawns
- Modified `_forward_to_server()` to detect new connections and restore cached state

**Files modified:**
- `lib/mcp_router.py` - Added caching logic (lines ~390-435, 900-970)

**Tests:** All 31 tests pass
